FAQ

Good to know.

Is Actua free?

Yes. Actua is free and open source. There is no subscription for the app.

Is Actua the official Actual Budget app?

No. Actua is an independent community project and is not the official Actual Budget application.

Where can I report a problem?

Use the GitHub issue tracker or join Discord to discuss a problem with the community.

What is Actual Budget?

Actual Budget is a privacy-focused, local-first personal finance and budgeting application. Visit the official Actual Budget website to learn more.
